# QO-100 Satellite Reception — Dhaka Rooftop SDR Project

## Overview
This project documents my hands-on reception and analysis of **QO-100 / Es'hail-2 amateur satellite signals** from a rooftop setup in **Dhaka, Bangladesh** using SDR and RF equipment.

The project demonstrates practical experience with satellite communications, antenna alignment, RF signal chains, SDR software, spectrum/waterfall analysis, and field troubleshooting.

## Skills Demonstrated
- Satellite signal reception
- Software Defined Radio (SDR)
- RF spectrum and waterfall analysis
- Antenna setup/alignment
- Feedline and RF signal-chain troubleshooting
- Linux/computer-based radio tools
- Technical documentation

## Project Workflow
1. Prepare rooftop receiving equipment.
2. Align the antenna/dish for QO-100 reception.
3. Connect the RF front end and SDR receiver.
4. Configure SDR software and appropriate receive parameters.
5. Locate and observe the QO-100 downlink spectrum.
6. Optimize reception and document results.
